# Vyro Client
Eigener kleiner Fabric-Client fuer Minecraft 1.21.11 (kein Meteor noetig).
- Menue: Rechte Shift-Taste
- Module: Sprint, BunnyHop, Glow, Flight
- HUD: Watermark + aktive Module

Benoetigt: Fabric Loader + Fabric API.
Die .jar baut GitHub Actions automatisch (Reiter Actions -> Artifacts).
